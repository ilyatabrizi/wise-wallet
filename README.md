# Wise Wallet

A personal euro wallet simulator with one virtual card. Open the published GitHub Pages site in iPhone Safari, tap Share, choose Add to Home Screen, enable Open as Web App and tap Add. Launch from the new icon once while online to cache the app.

In Settings you can change the sample balance, cardholder, display digits and monthly limit. Add or edit income, spending, investments, assets, liabilities and goals. Net worth is cash plus investments and assets minus liabilities.

The optional six-digit PIN encrypts the wallet on this device. Keep your PIN safe. Clearing the app's website data can erase your entries. Your edits stay on your device.

## iPhone installation

Open your private setup link in Safari and wait for the light Home screen. Tap Share → Add to Home Screen, keep Open as Web App enabled, and tap Add. Open the new icon once online. The initials at the top left open Settings. Older installations use the same wallet storage key. iOS may give each installed copy its own storage, so keep any older icon that contains entries you need.

The private appearance package supplies the install artwork and card image. The installation link carries its key in the URL fragment. Balance changes, recipients, exchange examples, requests and payment plans run locally. Apple Watch provisioning and bank payments require an issuer.
